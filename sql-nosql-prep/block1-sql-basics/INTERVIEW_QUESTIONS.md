# 🎯 Вопросы для собеседования: Основы SQL

## Базовые вопросы (1-10)

### 1. Что такое SQL и какие основные операторы?

**Ответ:**
SQL — язык запросов для работы с БД.

**Операторы:**
- SELECT — выборка
- INSERT — вставка
- UPDATE — обновление
- DELETE — удаление
- CREATE — создание
- DROP — удаление таблицы

---

### 2. В чём разница между WHERE и HAVING?

**Ответ:**
- WHERE фильтрует строки ДО группировки
- HAVING фильтрует результаты ПОСЛЕ группировки

```sql
SELECT customer_id, COUNT(*)
FROM orders
WHERE status = 'completed'  -- ДО
GROUP BY customer_id
HAVING COUNT(*) > 1;        -- ПОСЛЕ
```

---

### 3. Что такое NULL и как с ним работать?

**Ответ:**
NULL — отсутствие значения.

```sql
-- Правильно:
WHERE column IS NULL
WHERE column IS NOT NULL

-- Неправильно:
WHERE column = NULL  -- Всегда false!
```

---

### 4. В чём разница между = и IS NULL?

**Ответ:**
- `=` для сравнения значений
- `IS NULL` для проверки на NULL

```sql
WHERE city = 'Москва'     -- Сравнение
WHERE city IS NULL        -- Проверка на NULL
```

---

### 5. Что делает DISTINCT?

**Ответ:**
Возвращает уникальные значения:

```sql
SELECT DISTINCT city FROM customers;
```

---

### 6. Какие операторы сравнения вы знаете?

**Ответ:**
`=`, `<>`, `!=`, `>`, `<`, `>=`, `<=`

---

### 7. Что делает LIKE и какие спецсимволы?

**Ответ:**
Поиск по шаблону:
- `%` — любое количество символов
- `_` — один любой символ

```sql
WHERE name LIKE 'A%'      -- Начинается на A
WHERE name LIKE '%A'      -- Заканчивается на A
WHERE name LIKE '%A%'     -- Содержит A
WHERE name LIKE '_A%'     -- Второй символ A
```

---

### 8. В чём разница между AND и OR?

**Ответ:**
- AND — оба условия истинны
- OR — хотя бы одно условие истинно

---

### 9. Что делает ORDER BY?

**Ответ:**
Сортировка результатов:

```sql
ORDER BY price ASC   -- По возрастанию
ORDER BY price DESC  -- По убыванию
```

---

### 10. Что делают LIMIT и OFFSET?

**Ответ:**
- LIMIT — ограничивает количество строк
- OFFSET — пропускает строки

```sql
LIMIT 10 OFFSET 20  -- Пропустить 20, взять 10
```

---

## Продвинутые вопросы (11-20)

### 11. В чём разница между UNION и UNION ALL?

**Ответ:**
- UNION — объединяет без дубликатов (медленнее)
- UNION ALL — объединяет с дубликатами (быстрее)

---

### 12. Что такое BETWEEN?

**Ответ:**
Диапазон значений (включая границы):

```sql
WHERE price BETWEEN 100 AND 1000;
-- Эквивалентно:
WHERE price >= 100 AND price <= 1000;
```

---

### 13. Что делает IN?

**Ответ:**
Проверка на принадлежность списку:

```sql
WHERE city IN ('Москва', 'СПб', 'Казань');
```

---

### 14. Что такое COALESCE?

**Ответ:**
Возвращает первое не-NULL значение:

```sql
SELECT COALESCE(city, 'Не указан') FROM customers;
```

---

### 15. Какие агрегатные функции вы знаете?

**Ответ:**
COUNT, SUM, AVG, MIN, MAX

---

### 16. В чём разница между COUNT(*) и COUNT(column)?

**Ответ:**
- COUNT(*) — считает все строки (включая NULL)
- COUNT(column) — считает не-NULL значения

---

### 17. Что такое CASE?

**Ответ:**
Условная логика:

```sql
CASE 
    WHEN price < 1000 THEN 'Дёшево'
    WHEN price < 10000 THEN 'Средне'
    ELSE 'Дорого'
END
```

---

### 18. Как форматировать даты?

**Ответ:**
```sql
TO_CHAR(order_date, 'DD.MM.YYYY')
```

---

### 19. Что делает EXTRACT?

**Ответ:**
Извлекает часть даты:

```sql
EXTRACT(YEAR FROM order_date)
```

---

### 20. Как вставлять данные из одной таблицы в другую?

**Ответ:**
```sql
INSERT INTO table2 (col1, col2)
SELECT col1, col2 FROM table1 WHERE condition;
```
