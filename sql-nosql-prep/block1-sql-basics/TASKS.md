## 📌 Подсказки

<details>
<summary>Подсказка: Операторы сравнения</summary>

```sql
=     -- равно
<>    -- не равно
>     -- больше
<     -- меньше
>=    -- больше или равно
<=    -- меньше или равно
```
</details>

<details>
<summary>Подсказка: Логические операторы</summary>

```sql
AND   -- оба условия должны быть истинны
OR    -- хотя бы одно условие истинно
NOT   -- отрицание
```
</details>

<details>
<summary>Подсказка: LIKE паттерны</summary>

```sql
'abc%'  -- начинается на 'abc'
'%abc'  -- заканчивается на 'abc'
'%abc%' -- содержит 'abc'
'a_c'   -- 'a', любой символ, 'c'
```
</details>

<details>
<summary>Подсказка: NULL проверки</summary>

```sql
-- Правильно:
WHERE column IS NULL
WHERE column IS NOT NULL

-- Неправильно:
WHERE column = NULL  -- Всегда вернёт пустой результат!
```
</details>

<details>
<summary>Подсказка: COALESCE</summary>

```sql
-- Возвращает первое не-NULL значение
SELECT COALESCE(city, 'Не указан') 
FROM customers;
```
</details>
