## 📌 Подсказки

<details>
<summary>Подсказка: INNER JOIN синтаксис</summary>

```sql
SELECT columns
FROM table1
INNER JOIN table2 ON table1.column = table2.column;
```
</details>

<details>
<summary>Подсказка: LEFT JOIN для поиска отсутствующих</summary>

```sql
-- Найти клиентов без заказов
SELECT c.*
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id
WHERE o.id IS NULL;
```
</details>

<details>
<summary>Подсказка: EXISTS vs IN</summary>

```sql
-- EXISTS (быстрее для больших таблиц)
WHERE EXISTS (SELECT 1 FROM orders WHERE customer_id = customers.id)

-- IN (проверяет все значения)
WHERE id IN (SELECT customer_id FROM orders)
```
</details>

<details>
<summary>Подсказка: CTE синтаксис</summary>

```sql
WITH cte_name AS (
    SELECT columns FROM table
)
SELECT * FROM cte_name WHERE condition;
```
</details>
