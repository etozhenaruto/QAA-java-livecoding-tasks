# 🎯 Вопросы для собеседования: Оптимизация и индексы

## Базовые вопросы (1-10)

### 1. Что такое индекс и зачем он нужен?

**Ответ:**
Индекс — структура для ускорения поиска.

**Плюсы:** Быстрый поиск
**Минусы:** Медленнее запись, занимает место

---

### 2. Какие типы индексов вы знаете?

**Ответ:**
- B-Tree (по умолчанию)
- Hash
- Composite (составной)
- Unique
- Covering

---

### 3. Что такое B-Tree индекс?

**Ответ:**
Сбалансированное дерево. Подходит для:
- =, >, <, BETWEEN
- ORDER BY

---

### 4. Что такое Hash индекс?

**Ответ:**
Только для = (точное совпадение).

---

### 5. Что такое составной индекс?

**Ответ:**
Индекс по нескольким столбцам:

```sql
CREATE INDEX idx ON orders(customer_id, order_date);
```

**Правило:** Работает левый префикс.

---

### 6. Что такое Covering Index?

**Ответ:**
Индекс содержит все данные для запроса:

```sql
CREATE INDEX idx ON orders(customer_id, total);
SELECT customer_id, total FROM orders WHERE customer_id = 1;
```

---

### 7. Что такое EXPLAIN?

**Ответ:**
Показывает план выполнения запроса.

---

### 8. Какие типы сканирования вы знаете?

**Ответ:**
- Seq Scan — последовательное (медленно)
- Index Scan — сканирование индекса
- Index Only Scan — только индекс (быстро)
- Bitmap Index Scan — комбинация индексов

---

### 9. Что такое Seq Scan и когда он используется?

**Ответ:**
Полное сканирование таблицы.

**Когда:**
- Маленькие таблицы
- Нет индекса
- Большая часть таблицы

---

### 10. Что такое Index Only Scan?

**Ответ:**
Данные берутся только из индекса (без обращения к таблице).

---

## Продвинутые вопросы (11-20)

### 11. Как оптимизировать медленный запрос?

**Ответ:**
1. EXPLAIN ANALYZE
2. Добавить индекс
3. Оптимизировать запрос (SELECT нужные столбцы)
4. Избегать функций в WHERE

---

### 12. Почему индекс не используется?

**Ответ:**
- Функция в WHERE: `DATE(order_date)`
- LIKE с ведущим `%`: `LIKE '%text%'`
- Неправильный тип данных
- Статистика устарела

---

### 13. Что такое N+1 проблема?

**Ответ:**
N+1 запрос вместо одного:

```python
# ПЛОХО
for customer in customers:
    orders = query("SELECT * FROM orders WHERE customer_id = ?", customer.id)

# ХОРОШО
query("SELECT * FROM orders JOIN customers ...")
```

---

### 14. Что такое нормализация?

**Ответ:**
Разделение данных на таблицы для уменьшения дублирования.

---

### 15. Что такое денормализация?

**Ответ:**
Добавление дублирующих данных для ускорения чтения.

---

### 16. Когда нормализовать, а когда денормализовать?

**Ответ:**
- Нормализация: частая запись, целостность
- Денормализация: частое чтение, скорость

---

### 17. Что такое ACID?

**Ответ:**
- Atomicity — атомарность
- Consistency — согласованность
- Isolation — изоляция
- Durability — долговечность

---

### 18. Какие уровни изоляции вы знаете?

**Ответ:**
- READ UNCOMMITTED
- READ COMMITTED
- REPEATABLE READ
- SERIALIZABLE

---

### 19. Что такое грязное чтение (Dirty Read)?

**Ответ:**
Чтение незакоммиченных данных.

---

### 20. Как оптимизировать COUNT на большой таблице?

**Ответ:**
- Частичный индекс: `CREATE INDEX ... WHERE status = 'completed'`
- Приблизительный счёт из системных таблиц
- Кэширование результата
