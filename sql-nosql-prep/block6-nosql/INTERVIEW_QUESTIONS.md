# 🎯 Вопросы для собеседования: NoSQL

## Базовые вопросы (1-10)

### 1. Что такое NoSQL и когда использовать?

**Ответ:**
NoSQL — нереляционные БД.

**Когда:**
- Большие объёмы данных
- Горизонтальное масштабирование
- Гибкая схема
- Высокая нагрузка на запись

---

### 2. Какие типы NoSQL вы знаете?

**Ответ:**
- Document (MongoDB)
- Key-Value (Redis)
- Column-Family (Cassandra)
- Graph (Neo4j)

---

### 3. Что такое CAP теорема?

**Ответ:**
Только 2 из 3:
- Consistency — согласованность
- Availability — доступность
- Partition Tolerance — устойчивость к разделению

---

### 4. В чём разница между ACID и BASE?

**Ответ:**
- ACID (SQL) — строгая согласованность
- BASE (NoSQL) — согласованность в конечном счёте

---

### 5. Что такое шардирование?

**Ответ:**
Разделение данных между серверами.

---

### 6. Что такое репликация?

**Ответ:**
Копирование данных на несколько серверов.

---

### 7. Когда использовать SQL vs NoSQL?

**Ответ:**
- SQL: транзакции, сложные запросы, структурированные данные
- NoSQL: масштабирование, гибкая схема, большие данные

---

### 8. Что такое MongoDB и когда использовать?

**Ответ:**
Document store. Для:
- Контент-менеджмент
- Каталоги
- Профили пользователей

---

### 9. Что такое Redis и когда использовать?

**Ответ:**
Key-Value store. Для:
- Кэширование
- Сессии
- Рейтинги
- Очереди

---

### 10. Что такое Cassandra и когда использовать?

**Ответ:**
Column-family store. Для:
- Временные ряды
- Логи
- IoT данные

---

## Продвинутые вопросы (11-20)

### 11. Что такое Neo4j и когда использовать?

**Ответ:**
Graph database. Для:
- Социальные сети
- Рекомендации
- Обнаружение мошенничества

---

### 12. Что такое eventual consistency?

**Ответ:**
Согласованность в конечном счёте — данные станут согласованными со временем.

---

### 13. В чём разница между CP и AP системами?

**Ответ:**
- CP (MongoDB) — при разделении недоступны
- AP (Cassandra) — при разделении возвращают старые данные

---

### 14. Что такое полиглотное хранение?

**Ответ:**
Использование разных БД для разных задач:
- PostgreSQL — основные данные
- Redis — кэш
- Elasticsearch — поиск

---

### 15. Как MongoDB хранит данные?

**Ответ:**
BSON (бинарный JSON).

---

### 16. Что такое агрегация в MongoDB?

**Ответ:**
Конвейер операций:

```javascript
db.orders.aggregate([
    { $match: { status: "completed" } },
    { $group: { _id: "$customer_id", total: { $sum: "$amount" } } }
]);
```

---

### 17. Какие команды Redis вы знаете?

**Ответ:**
- SET, GET
- HSET, HGETALL
- LPUSH, LRANGE
- ZADD, ZRANGE
- EXPIRE, TTL

---

### 18. Что такое TTL в Redis?

**Ответ:**
Время жизни ключа:

```bash
SET key value EX 3600  # 1 час
```

---

### 19. Что такое Materialized View в Cassandra?

**Ответ:**
Автоматически поддерживаемое представление с другим ключом.

---

### 20. Что такое Cypher в Neo4j?

**Ответ:**
Язык запросов для графов:

```cypher
MATCH (p:Person)-[:FRIENDS]->(f)
RETURN p.name, f.name
```
